# US Repeater Coordinator Reference
**Source:** W2XQ.com (updated Dec 5, 2025) — most authoritative post-NFCC
**NFCC dissolved 2017. ARRL has no complete list. W2XQ is the de-facto master.**
**For eQRA use:** See "Data Accessibility Tier" — only Tier A/B usable in code.

---

## Master Reference
- W2XQ Full List: https://w2xq.com/bm-repeaters.html ⭐ primary
- ARRL (informational only): https://www.arrl.org/frequency-coordinators
- ARRL Repeater Directory 2025 (powered by RepeaterBook): 22,319 US/Canada listings

## eQRA Implementation Notes
- **Primary source for all states:** RepeaterBook (public HTML scraping, no API key)
- **Tier A supplement (FL, MN, WA):** Direct CSV fetch — true distance filtering possible
- **Tier B supplement (SoCal):** SCRRBA HTML scraping — verify 2m page exists before using
- **All others (Tier C/D):** RepeaterBook only — coordinator data inaccessible programmatically
- **TASMA warning:** SoCal 2m coordinator transitioning to hamclubonline — use SCRRBA or RB instead
